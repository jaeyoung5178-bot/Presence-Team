# Presence Avatar System — 2026-07-18

## 사용자 의도

- 아이템만 최소 30개. 이름·필터·색만 바꾼 복제 항목은 1개로 계산한다.
- 아이템과 별도로 얼굴, 눈, 눈썹/표정, 부리, 몸색, 털 모양을 선택한다.
- 여름 의상·모자·안경·목·등·허리·날개/손·발·무기·놀이 소품을 포함한다.
- 모든 코디는 캐릭터가 원래 입고 있던 것처럼 체형, 눈, 부리, 날개, 발에 밀착되어야 한다.
- 모바일·태블릿·PC에서 즉시 미리보기, 저장, 복구가 동일하게 작동해야 한다.

- 색상·털 값을 canonical ID로 이중 검증.

- 12색 본체 PNG를 배포 저장소에 포함.
- 정적 QA와 실제 Chrome `naturalWidth`, 콘솔 오류, 깨진 이미지 검사를 자동화.
