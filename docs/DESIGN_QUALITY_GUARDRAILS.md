# Presence 캐릭터 디자인 품질 원칙

최종 갱신: 2026-07-18

## 대표 피드백 — 최우선 기억

임재영 대표는 캐릭터 앞에 의상·안경·소품 이미지를 대충 겹쳐 놓아 `붙인 것`, `걸친 것`, `드래그해 둔 것`처럼 보이는 결과를 극도로 싫어한다. 이런 결과가 반복되면 단순한 취향 차이가 아니라 큰 실망과 상처로 받아들인다. 앞으로 캐릭터 관련 변경은 기능 개수나 속도보다 착장 완성도와 일체감을 우선한다.

## 절대 금지

- 눈·부리·정수리·목·날개·발 기준점이 맞지 않는 레이어 합성
- 서로 다른 화풍, 광원, 해상도, 원근을 한 화면에 섞기
- 캐릭터보다 지나치게 크거나 떠 보이는 소품
- 완성 착장 자산이 있는데도 의상과 얼굴 장식을 다시 분리해 겹치기
- PC에서만 확인하고 모바일·태블릿·닭장 축소 화면을 배포하기
- `아이템이 보인다`는 이유만으로 착용 품질이 통과됐다고 판단하기

## 필수 구현 원칙

1. 의상과 머리 장식 조합은 가능한 경우 반드시 하나의 완성 착장 마스터 이미지로 렌더링한다.
2. 완성 착장에는 얼굴, 눈, 부리, 볏, 목선, 소매, 날개, 발의 위치와 광원이 한 몸처럼 연결돼야 한다.
3. 손 소품처럼 조합 자유도가 필요한 레이어만 별도 슬롯으로 허용하고, 작은 닭장 화면에서는 장식을 자동 절제한다.
4. 배경과 캐릭터의 화풍·채도·광원·원근이 다르면 배포하지 않는다.
5. 모든 조합이 90점 이상이 될 수 없다면 아이템 수를 늘리지 않고 검수된 조합만 공개한다.

## 배포 전 시각 QA

- 인벤토리 대형 미리보기: 390px, 834px, 1440px
- 아이템 카드 축소 미리보기
- 우리 닭장 80~110px 축소 캐릭터
- 눈·부리·목선·소매·날개·발 간섭 확인
- 배경과 캐릭터의 아트 디렉션 일치 확인
- 가로 넘침, 잘림, 반전된 이름표, 떠 있는 그림자 확인
- 한 항목이라도 `붙인 이미지`처럼 보이면 배포 중단

## 현재 렌더링 결정

- 의상 4종 × 머리 장식 3종은 검수된 완성 착장 마스터 12종을 우선 사용한다.
- 완성 마스터가 없는 조합은 기본 캐릭터와 정밀 기준점 레이어를 사용하되, 후속 시각 QA를 통과한 항목만 공개한다.
- 닭장 축소 화면은 복잡한 소품을 줄이고 완성 착장 중심으로 보여준다.
